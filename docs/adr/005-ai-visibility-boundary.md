# ADR-005: AI Visibility is a bounded intelligence module

**Status:** Accepted by founder, 2026-10-04; no amendments.

## Decision

AI Visibility produces repeatable observations, findings, actions and experiment results. It can propose Opportunity candidates but does not equal buying intent and is not a standalone generic dashboard in the current roadmap.

## Consequences

Observed visibility and technical readiness remain distinct. Full module implementation waits for Opportunity Core validation.
